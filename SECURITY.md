# Security Policy

## Reporting a vulnerability

If you've found a security issue in Caladia, please report it privately
to **admin@caladia.ai**. Don't open a public issue.

You can expect:

- An acknowledgement within 5 business days.
- A first assessment within 14 days.
- Coordinated disclosure once a fix is available.

## Scope

In scope:

- The Caladia web app (this repo) — including the importers, simulation
  engine, and any code that runs on `caladia.ai`.
- The schema and file-format packages.

Out of scope:

- Vulnerabilities in third-party services that Caladia integrates with
  (e.g. Cloudflare).
- Issues that require physical access to a user's device or already-
  compromised credentials.

## Acknowledgements

We're happy to credit reporters in release notes if you'd like.
